# Free Code Editor 1.1.0

本次更新加入 AI 開發 Agent，並修正 Linux 中文字型備援與 Windows CI 相容性。

## 更新內容

- AI 面板支援 OpenAI 相容 API 與本機 Ollama，提供串流對話、連線測試及不使用工具的聊天模式。
- Agent 可搜尋、讀檔、多檔新增／修改／刪除及執行獨立 shell 命令；確認模式提供差異預覽與逐次批准，自動模式每次任務需明確授權，可隨時停止。
- API Key 可僅存記憶體，或保存至 macOS Keychain、Windows Credential Manager、Linux Secret Service。每工作區保存對話與工具紀錄，重啟不自動續跑。
- 文件修改保留中文編碼、CRLF 與權限，並檢查外部衝突及未儲存編輯；批次逐檔回報結果。
- 介面、編輯區、差異檢視、Markdown 與終端機加入 Noto CJK 備援；Linux `.deb` 宣告 `fonts-noto-cjk`／`fontconfig` 依賴。
- 隔離 Git 測試的換行設定，新增 Big5 在 `autocrlf=true` 下索引 LF／工作目錄 CRLF 的回歸測試。
- 統一 Windows Job Object FFI 宣告，修正 `clashing_extern_declarations` 編譯錯誤，保留嚴格警告檢查。

## 下載與安裝

推送 `v1.1.0` 後，三平台 CI 全部成功才會建立 GitHub Release，提供 macOS `.app.tar.gz`、Windows NSIS `.exe`／MSI、Linux `.deb`／AppImage 與 `SHA256SUMS.txt`。

- macOS 採 ad-hoc 簽章，尚未 Developer ID 簽署及公證。
- Windows 需要 WebView2，安裝包尚未配置發行者簽署。
- Linux 需要相容的 WebKitGTK 4.1。建議使用 `sudo apt install ./檔名.deb` 解析字型依賴；AppImage 主機需自行安裝 CJK 字型。Ubuntu 可執行 `sudo apt install fonts-noto-cjk fontconfig`、`fc-cache -f`，再重啟編輯器。
- AI 連線需要系統 curl；Linux 保存 API Key 另需可用的 Secret Service 與 `secret-tool`（Ubuntu／Debian 的 `libsecret-tools`）。Ollama 服務與模型須自行安裝及啟動。

## 驗證與限制

macOS 本機 Rust 57 項、Node 63 項測試通過，另 1 項 Make 測試略過；格式、Clippy、前端建置、macOS 打包與簽章檢查通過。

本機測試涵蓋原生 Agent 迴圈、雙檔修改、真正 shell 指令、程序型 SSE fixture、取消／逾時、檔案完整性與 Git 換行設定隔離。實際模型連線、系統憑證庫操作、Ubuntu 24.04 中文畫面與完整三平台桌面互動仍待目標環境驗收；本機測試及打包不等同這些項目已通過。

Agent 自動模式的命令以目前使用者權限執行，可存取工作區外資料與網路，不是 sandbox。停止不撤銷已完成的修改；批次不具整批交易原子性。文件工具採保守的排除規則，未完整實作 Git ignore parser。每次任務最多 30 輪，對話請求內容預算 64 KiB，歷史上限 8 MiB。

輸入時的 AI 行內補全、MCP、網頁瀏覽及多 Agent 不在本版範圍。文字檔仍上限 100 MiB，工作階段備份上限 32 MiB；UTF-16／UTF-32 尚不支援。其他限制見 [README](https://github.com/marksyang/free-code-editor/blob/v1.1.0/README.md) 與 [桌面驗證紀錄](https://github.com/marksyang/free-code-editor/blob/v1.1.0/docs/desktop-verification.md)。
