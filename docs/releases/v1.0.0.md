# Free Code Editor 1.0.0

首個 1.0.0 發行版，採 Rust／Tauri 2、React、TypeScript 與 Monaco Editor。

- 語法上色：C、C++、Rust、JavaScript、TypeScript／TSX、JSON、Python、Perl、Bash、CSS、HTML、Makefile、Markdown、Puppet、Pascal 與 BitBake。
- 資料夾樹狀瀏覽與按需載入、快速開檔、資料夾範圍搜尋、分割編輯、未儲存內容恢復及唯讀差異比較。
- Markdown 預覽、表格、工作清單與本機圖片；保留 Makefile 的 Tab recipe。
- 可設定 LSP，提供補全、診斷、跳轉與符號重新命名。
- Git 狀態、暫存／取消暫存、提交及提交歷史與歷史差異。
- xterm.js 終端機，使用 Unix PTY／Windows ConPTY；支援本機 Nerd Font。
- Windows ConPTY 隔離父程序標準串流，修正 CI 重新導向環境下 PowerShell 提前退出的問題，並加入專用回歸測試。

## 下載與安裝

Release assets 由三平台 CI 全部通過測試與打包後產生；檔名包含平台與 CPU 架構，請選擇符合電腦的檔案。

- macOS：下載 `.app.tar.gz`，解壓後將 `.app` 移至 Applications。使用 ad-hoc 簽章，尚未完成 Developer ID 簽署與公證。
- Windows 10 1809+／Windows 11：使用 NSIS `.exe` 或 MSI；需要 WebView2，安裝包未配置發行者簽署。
- Linux：使用 `.deb` 或 AppImage，需要相容的 WebKitGTK 4.1 執行階段。AppImage 下載後先執行 `chmod +x 檔名.AppImage`。
- `SHA256SUMS.txt` 提供下載檔案的 SHA-256 校驗值。

## 已知限制

AI 連線、聊天、行內補全與 Agent 尚未完成。Git push／pull 透過終端機執行；尚無即時檔案監看、完整 `.gitignore` 解析與除錯器。LSP 格式化、Code Actions 與語意 token 尚未整合。文字檔支援 UTF-8、Big5／CP950、GBK／CP936、GB18030 原編碼讀寫，上限 100 MiB；工作階段備份仍上限 32 MiB。minimap 可關閉並保存設定；專案搜尋最多回傳 500 筆結果。

工作區服務已以 100,011 個檔案驗證。CI 測試與打包不等同三平台完整桌面互動驗收；驗證狀態與其他限制見 [README](https://github.com/marksyang/free-code-editor/blob/v1.0.0/README.md) 與 [桌面驗證紀錄](https://github.com/marksyang/free-code-editor/blob/v1.0.0/docs/desktop-verification.md)。
