# Free Code Editor 1.0.1

本次更新加入中文編碼讀寫、可關閉的 minimap，以及較大的文字檔容量。

## 更新內容

- 原生讀寫 Big5／CP950、GBK／CP936（相容 GB2312）與 GB18030；開檔可選擇編碼，儲存保留原編碼，另存新檔可轉碼。
- 無法表示的字元或無法無損往返的資料會拒絕寫入，避免替代字元造成內容遺失。
- 搜尋、Git 差異與 LSP 跨檔編輯支援所選文件編碼。
- minimap 可由工具列或命令面板開關，並隨工作階段保存。
- 單一文字檔上限提高至 100 MiB（104,857,600 bytes）。

## 下載與安裝

三平台 CI 全部通過後，GitHub Release 會提供 macOS `.app.tar.gz`、Windows NSIS `.exe`／MSI、Linux `.deb`／AppImage，以及 `SHA256SUMS.txt`。請依平台與 CPU 架構選擇下載檔案。

macOS 採 ad-hoc 簽章，尚未公證；Windows 安裝包未配置發行者簽署，需要 WebView2。Linux 需要相容的 WebKitGTK 4.1 執行階段。

## 驗證與限制

macOS 本機 Rust 測試 46 項、Node 測試 60 項通過，另 1 項 Make 測試略過。已用 `Device_ID.log` 暫存副本驗證 Big5 無損往返；原檔未修改。真實桌面互動、100 MiB 編輯效能與 Windows／Linux 原生編碼仍需目標平台驗收。

工作階段備份總上限仍為 32 MiB，大型文件可能無法備份；UTF-16／UTF-32 尚不支援。AI 功能仍未完成，其他限制見 [README](https://github.com/marksyang/free-code-editor/blob/v1.0.1/README.md) 與 [桌面驗證紀錄](https://github.com/marksyang/free-code-editor/blob/v1.0.1/docs/desktop-verification.md)。
